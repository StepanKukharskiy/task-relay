INSTALL TASK RELAY

From download to first job

A browser cannot run a shell command from an HTML file. The macOS setup file starts the installer when you open it from Finder.

MACOS · PRIMARY PATH

Install without typing commands

  1. Use Download source files above, then open the ZIP to extract its folder.
  2. If Python 3.11+ is missing, install Python for macOS ↗.
  3. Open the extracted job-relay folder in Finder and double-click Setup.command. macOS may ask you to confirm opening a downloaded script.
  4. Wait for the local setup page to open. Choose a project, connect a provider and Telegram bot, then follow its start instructions.

Keep the installation folder: it contains Relay’s dedicated Python environment. Reopen setup later by double-clicking Setup.command again.

BEFORE YOU START

What you need

  • Python 3.11+ on the computer. The installer cannot run before Python exists.
  • A project folder and an API provider key for new provider jobs, or existing Codex jobs.
  • A dedicated Telegram bot from BotFather ↗ if you want Telegram delivery.

The installer installs Relay and its required Python packages. Git is only needed to clone, not for the ZIP. Claude, browser automation, Blender and FFmpeg are optional. Linux uses sh install.sh from the extracted folder; Windows execution is not yet supported.
