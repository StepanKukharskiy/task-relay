Task Relay for Chrome

Support

Contact publisher Stepan Kukharskiy at stepan.kukharskiy@gmail.com.

Include the extension version, Chrome version, what you tried and the error. Share only what is needed to diagnose it; do not email passwords, keys or full private transcripts.

Getting started

Select useful text on a webpage, click the pinned Task Relay toolbar icon and choose Turn into Skill or Save work. Approve optional ChatGPT access once for autofill. Relay opens ChatGPT with the request ready; review it, press Send and then download. With autofill enabled, you do not need a second toolbar click or manual paste. Return to ChatGPT, Place request and Paste AI reply are recovery controls in Options.

No access or no selection

Click Task Relay’s toolbar icon on the exact tab you are using. Select nonempty text from the conversation again. Chrome internal pages and the Chrome Web Store cannot be captured.

Recovering a result

If you deleted the prepared draft, use Restore message. If Chrome cleared the temporary panel state, return to the original chat and use Options → Recover this chat’s result. Expand a collapsed Relay request first. The request and its completed matching response must be loaded.

Using saved work later

Keep your downloaded Skill or work file. Supply it in a fresh AI chat, or use Options → Open files to prepare context you can copy. Relay cannot automatically discover every previous export or the latest ChatGPT Library file.

Optional Desktop mode

The portable path does not need Desktop. Connecting a local library requires separate native-bridge registration. Disconnect Desktop removes the permission; existing local library data remains yours.

Privacy requests

Use the same support email to request deletion of support messages. Captures are stored locally; downloaded files, sent AI messages and Desktop records must be managed in their respective environments.
