Picking up work in a new chat

Attach or explicitly select the saved Skill or work snapshot. Task Relay cannot search your entire Library or retrieve the latest file automatically. Keep the files you exported.

Privacy requests

Use the same email address for privacy questions or deletion requests concerning support messages. Task Relay has no project-content store for this skills-only workflow. Files you saved in ChatGPT or on your device must be managed there.
