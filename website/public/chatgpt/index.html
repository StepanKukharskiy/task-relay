Turn useful ChatGPT conversations into reusable Skills and work you can pick up again.

Make this reusable

After useful discussion, invoke Task Relay and ask Make this reusable. ChatGPT proposes general know-how as a standard Agent Skill, and instance-specific progress as a work snapshot. Review, edit, save or ignore each independently. Nothing is saved automatically.

Continue saved work

In a fresh chat, attach or select your saved Skill, work snapshot or both. Say what you want to do next. ChatGPT uses those files and the new request; you do not need to reconstruct the original conversation.

Keep the right information

A Skill says how to do similar work. It uses the standard SKILL.md format with useful supporting resources. A work snapshot keeps the objective, conclusions, decisions and proposals, evidence, artifact references, unresolved questions and next actions.

Update saved work proposes a new work revision. Improve Skill proposes a reusable lesson. Review and save them separately. Previous files are not overwritten and Skills are not installed automatically.

Uses native ChatGPT controls

Task Relay is a skills-only plugin using ChatGPT's conversation and file capabilities. It requires no Relay server, tunnel, separate Relay account or Relay Desktop. File creation and selection depend on the capabilities available in the current chat.

It works from current context and explicitly supplied material. It cannot scan all your chats, discover the latest Library file automatically, execute local tools or maintain a synchronized catalog. An artifact reference does not include that artifact's contents.

Release status: skills-only version 0.4.0 is being tested and prepared for public review. A public directory listing has not been published.
