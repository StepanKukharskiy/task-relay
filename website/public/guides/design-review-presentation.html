Task Relay guides · Research / Model / Present

Assemble research and model images into an editable deck

Use your selected evidence and render files to make a new design-review PPTX with editable captions, tables and charts.

The problem people report

An architect asks how to insert a floor plan clearly into PowerPoint. This is a specific report about drawing readability, not evidence of widespread demand for automatic deck creation. The workflow here addresses assembly and consistent presentation; it cannot recover detail missing from a low-resolution source image.

Select the material first

You provide: an approved outline, research notes and citations, numeric chart data with units, selected PNG/JPEG images, and the audience. Include the model revision and view name in each render's caption. For line-heavy drawings, use a readable export supplied from the authoring app.

You get: a new PPTX with native text, shapes, tables, column/bar/line charts and embedded images. PPTX generation runs locally; it needs no PowerPoint installation or Google account. A configured worker prepares and reviews the slide specification.

Before you start

These instructions are matched to the capabilities bundled in Relay 0.13.24, checked on 15 September 2026. The website download is still 0.13.0-beta.1; it does not establish availability of this whole workflow. Ask your running Relay to check the required tools before starting.

Use a configured worker to prepare and review the work. Select the exact input files, review the proposed plan, then press Start. For model edits, Relay prepares the code first and asks you to approve that exact code before running it in the local app.

Give Relay this request

Create a new six-slide design-review PPTX from my selected outline,
research notes, chart data and model images. Use these sections:
brief, site evidence, model overview, option comparison, open questions,
and sources. Flag missing content instead of inventing it.
Keep titles, captions, tables and charts editable. Fit images without
stretching; identify the model revision and view in the captions.
First show me the outline and image choices. After I select them,
prepare/review the slide specification and create the PPTX.
Check the actual file against the sources and return it for me to open
and review. Do not replace the deck with flattened slide images.

Make the first deck easy to check

  1. Choose a small set of evidence and images. Keep source data separate from conclusions.
  2. Review the outline, image choices and comparison criteria before deck creation.
  3. Run the presentation stage. Relay checks the generated file's text, table/chart data and embedded images.
  4. Open the actual PPTX in your presentation app. Check small labels, image resolution, fonts and layout before selecting it.

PNG/JPEG model views remain raster images; Relay does not convert a .3dm, .blend or PDF directly into editable slide geometry. The current operation creates a new deck. Existing-template editing, native .key files and automatic PDF or slide-image previews need separate tooling. Keynote import fidelity also needs a visual check in Keynote.

Start upstream with site research or Rhino named-view renders. The Barcelona sample demonstrates editable charts and source notes, but was authored with separate local tools.

Capability check: pptx.create are present in the audited app bundle. See the operation documentation for implementation scope and recorded checks. This article is a workflow recipe; its exact prompt has not been qualified through a complete live Relay run. Forum reports establish a problem, not measured time savings.
