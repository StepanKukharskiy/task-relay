Task Relay guides · Research / Model / Present

Less repetition between research, models and slides

Practical workflows for browser research, Rhino, Blender and editable PowerPoint files. Built around specific problems people have reported.

Start with a repeated piece of work in the tools you already use: gathering site evidence, revising a model, exporting views or assembling slides. Each guide links to a reported problem and explains which part Relay can handle.

Browser research → PPTX

Turn site research into a pre-schematic deck

Stop rebuilding the location, climate and vegetation research pack for every project. Collect the evidence once, review it, then make an editable presentation.

Rhino → checked .3dm + preview

Repeat a precise model edit in Rhino

Apply the same dimension change to selected objects, keep the rest of the model intact, and review a new .3dm version.

Rhino named views → PNGs

Render selected Rhino views for a design review

Reuse the cameras saved in your model and produce a consistent set of review images from the selected revision.

Blender → packed .blend + source bundle

Keep Blender assets and textures together

Prepare a portable candidate from selected mesh assets and image files, then check that it reopens after relocation.

Research + PNG/JPEG renders → PPTX

Assemble research and model images into an editable deck

Use your selected evidence and render files to make a new design-review PPTX with editable captions, tables and charts.

A useful first project

Research one site → select its evidence → revise a small Rhino model → render the chosen views → assemble a design-review PPTX. Start with one guide and inspect its result before joining the stages. Blender can supply its own model assets and previews.

Before you start

These instructions are matched to the capabilities bundled in Relay 0.13.24, checked on 15 September 2026. The website download is now 0.13.26 beta and includes these registered operations; complete live workflow qualification remains separate. Ask your running Relay to check the required tools before starting.

Use a configured worker to prepare and review the work. Select the exact input files, review the proposed plan, then press Start. For model edits, Relay prepares the code first and asks you to approve that exact code before running it in the local app.

What the evidence means: the guide set was checked against the bundled operation code in Relay 0.13.24. Linked forum posts document specific needs; none proves time savings or customer demand for Relay. The Barcelona deck is a worked artifact example. These exact natural-language workflows still need complete live trials.
