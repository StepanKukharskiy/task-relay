Skill page request counts

This page explains the publisher's request counting on the Excel-to-PowerPoint Skill page and their download links. It describes website behavior, separately from your agent and Relay execution.

What the website records

For recognized page/download requests, the application writes the day, Skill name, event type and a fixed campaign label for a versioned Medium article, a versioned website guide, the personal-site article or a direct visit. The record contains no visitor ID, IP address, cookie, user-agent string, referrer, raw URL/query, request body or work content.

The browser's user-agent and prefetch headers are checked in memory to exclude common bots and previews; those header values are not copied into these event records. Requests with Do Not Track or Global Privacy Control set to 1 are not counted. Downloads still work. The publisher can disable these counts on the server.

What a count means

A count is a website request, not a unique person, completed download, installation, Skill execution or retained user. Repeated requests and unrecognized bots can affect totals. No analytics cookies, fingerprints or cross-site visitor profiles are created.

Your agent and Skill files

The downloaded Skill and reference scripts contain no publisher telemetry endpoint. Running them does not send an execution event to this website. Your selected host, model and tools process inputs according to your own provider settings and their terms; model calls can involve an external service.

Hosting and retention

This website is hosted by Railway. Its infrastructure may process connection metadata and operational logs under Railway's privacy policy. The publisher's small event records are held in operational logs; no additional analytics service or analytics database is configured for this experiment. No fixed hosting-log retention period is promised.
