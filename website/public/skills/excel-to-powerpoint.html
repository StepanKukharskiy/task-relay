Use in Codex

  1. Download and unzip the Skill. Put its excel-to-powerpoint folder in your project's .agents/skills directory.
  2. Download the example and give Codex its workbooks, template and reviewed mapping.
  3. Ask Codex to use the Skill and save a new output. Follow the included runtime reference; restart Codex if the Skill does not appear.
Use $excel-to-powerpoint to update the January template from example/february.xlsx and example/report-mapping.json. Follow example/request.txt, keep charts editable, and save to a new results path.

Required document tools must be available in the host. Automatic discovery and a CLI without these tools were not qualified. Review a new mapping before using your own report.

Tested scope

One prepared six-slide template, explicit mappings and real UCI Online Retail transactions. The original Relay trial and a direct Codex run passed the saved-file checks. One explanation remained for human input. Charts are editable snapshots.

Keynote opened the original output with formatting differences and a font warning. Native PowerPoint and arbitrary templates remain untested.
