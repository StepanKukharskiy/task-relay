Task Relay coordinates AI agents, local applications and multi-step project work from Telegram. It keeps track of the handoffs, files and decisions, so you can focus on the work.

Get Task Relay ↗
01 / Overview

From request
to reviewed result.

Send a request in your messenger. Relay finds the right task or helps you prepare a workflow, with clear inputs, outputs and steps to review before work starts.

Agents and tools do their part. You choose an output, ask for a revision, pause or continue. Original requests, file versions and decisions stay attached to the work, even after a restart.

Relay runs on your computer. Your selected AI providers handle the work; Telegram brings back progress, files and questions. An optional Apple Messages text pilot is available on macOS.

02 / Tools

Bring the tools
you already use.

AI agents

Codex desktop tasks and CLI workers, managed Claude sessions, and Gemini workers. Use capable workers for project files, code changes and shell commands.

Text providers

OpenAI, Gemini, Qwen, DeepSeek and OpenRouter. Direct text routes can read project files; editing and command execution depend on the selected worker.

3D & local applications

Registered Blender operations and direct Rhino 7/8 on macOS: inspect models, prepare reviewed edits, produce native candidates and check previews.

Browser & production tools

Bounded browser tasks, an optional Perplexity account-browser pilot, and file or media tools available to your configured worker.

Connect your own accounts and install the tools you need. Availability depends on your host and worker. Relay does not automate every application; Grasshopper support is paused.

03 / Workflows

A starting point
for the next task.

These example workflows show the direction of current development. Starter selection is not included in this downloadable beta; begin with an instruction in Telegram and review the available next steps.

  1. Research → evidence → report

    Check sources, collect evidence and turn selected findings into an editable report.

  2. Architecture → model → presentation

    Research constraints, review a concept, build in Blender or Rhino, and prepare a presentation.

  3. Native model → revision → checked candidate

    Inspect an existing model, review an exact edit, then check the candidate and its preview.

  4. Approved carousel → reel → review

    Plan an adaptation from selected cards and assets, then produce and inspect a reel with configured media tools.

  5. Data → analysis → charts → presentation

    Validate a dataset, make reproducible calculations and build an editable presentation from the results.

Starters describe the steps and required tools. Each stage needs its own agreed scope; choosing a starter does not start the whole workflow or install missing integrations. These starters are part of current development.

Download for Mac ↓

Beta 0.12.1 · Apple Silicon · macOS 14+

Coming later · Execution not supported yet

  1. Install. Open the DMG, drag Task Relay into Applications, then eject the disk.
  2. Connect. Open the app and follow its saved setup steps: AI access, Telegram bot, background service and pairing.
  3. Start a conversation. Send your first instruction in Telegram. The companion stays in the menu bar for settings and controls.

Early beta: this build has no Apple Developer ID or notarization. After trying to open it, macOS may require Privacy & Security → Open Anyway. Only approve the download if you trust it. Apple’s opening instructions. Updates may require refreshing permissions; managed Macs may block this beta.

Python is included. You’ll need your own AI access and a dedicated Telegram bot; provider usage may cost money. First-time Messages setup remains a separate pilot. Optional tools such as Blender are installed separately.

Install with CLI instead

For developers on macOS or Linux. Requires Python 3.11+, curl and tar. Download this beta’s source, then run the guided terminal setup:

curl -fLO https://task-relay-website-production.up.railway.app/downloads/Task-Relay-0.12.1-beta.1-source.tar.gz
tar -xzf Task-Relay-0.12.1-beta.1-source.tar.gz
cd task-relay-0.12.1-beta.1
sh install.sh --terminal-setup

The installer creates its own environment and prints the installed CLI path. Keep that folder in place. Setup saves connections without starting provider work. Follow the printed instructions to start Relay and pair Telegram.

The CLI honors the data connection already selected in the companion. Existing login services are preserved; switching their owner requires a reviewed handoff. Linux service support depends on an available user service manager.
