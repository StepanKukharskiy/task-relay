01 / How it works

From request
to reviewed result.

Tell Relay what you need done.

Relay can route work through connected agents, applications and tools, while keeping the inputs, outputs and decisions attached to the job.

Review important steps, select the result you want to continue with, and let Relay carry that selection into the next stage.

02 / Workflows

One job can
cross many tools.

Brief → research → editable presentation

  1. Send the project brief.
  2. Use an AI worker to summarize requirements and research missing context.
  3. Review the selected findings.
  4. Generate an editable presentation.
  5. Keep the source material, selected outputs and final file connected to the same job.

Concept → 3D model → render → presentation

Relay can move work between an AI agent, Blender or Rhino, image and video tools, and presentation generation without treating every step as a separate conversation.

Plan and review each stage with the tools and accounts you have connected.

Explore the five workflow starters

This beta includes five versioned starters. Use /templates in Telegram or Messages to inspect them, then ask Relay to plan a stage.

  1. Research → evidence → report

    Check sources, collect evidence and turn selected findings into an editable report.

  2. Architecture → model → presentation

    Research constraints, review a concept, build in Blender or Rhino, and prepare a presentation.

  3. Native model → revision → checked candidate

    Inspect an existing model, review an exact edit, then check the candidate and its preview.

  4. Approved carousel → reel → review

    Plan an adaptation from selected cards and assets, then produce and inspect a reel with configured media tools.

  5. Data → analysis → charts → presentation

    Validate a dataset, make reproducible calculations and build an editable presentation from the results.

Starters describe the steps and required tools. Each stage needs its own agreed scope; choosing a starter does not start the whole workflow or install missing integrations. End-to-end workflow quality still needs qualification with your tools and accounts.

03 / Versions & decisions

Know what changed.

Relay records which outputs were produced from which selected inputs.

Replace a selected model and Relay can show which downstream outputs are affected, so you can review the impact and decide what should run again.

Changing an input does not automatically authorize a rebuild. You stay in control of what runs next.

AI agents

05 / Programs

What Relay
supports today.

These integrations are implemented in Task Relay. Connect your own accounts and install the tools you want to use. The 0.13.0 beta includes the features below; account access and installed tools determine what you can run.

Blender — modeling, rendering & animation

Create scenes from geometry data, inspect and revise selected models, import textures and objects, render previews, and animate transforms or cameras. Saves editable Blender files. Video encoding also needs FFmpeg and ffprobe.

Rhino 7 & 8 — modeling & rendering

Create, inspect and revise native Rhino models with reviewed Python scripts. Save in the selected Rhino version and render named views with Rhino Render. Requires Rhino and a usable license on macOS.

PowerPoint presentations — editable PPTX generation

Create presentations with editable text, shapes, tables, charts and images. Relay saves a native .pptx file without requiring PowerPoint or a Google account. Included in the Mac beta; CLI installations need the presentation extra.

Codex, Claude & Gemini — agent work

Continue Codex desktop tasks, run Codex CLI workers, use managed Claude sessions, or use Gemini file workers. Codex and Claude can edit files and run commands within their permissions; Gemini’s file-worker route writes declared text files.

OpenAI, Gemini, Qwen, DeepSeek & OpenRouter — text APIs

Run text conversations and read project files. A direct text API connection does not itself provide application control or file editing.

Gemini, Veo, Runway & Higgsfield — images, speech & video

Use Gemini for image generation/editing and speech, Veo for video, and Runway or Higgsfield for image and video generation. The available output depends on your selected model and account access.

Browser research & messaging

Enable Browser use in Settings to set up a dedicated Chrome profile and sign in to websites. Perplexity Search has a standalone worker; other websites need a supported browser executor. Verification challenges still require you. Telegram is the main task and file-delivery interface; Apple Messages is a separate macOS text pilot.

Direct local application execution is currently supported on macOS. Windows task execution is not supported yet. Grasshopper is paused; there is no native Keynote, Word, Excel or PowerPoint application-control integration.

Documents, spreadsheets & other exports

.docx, .xlsx, .pdf and .svg need a capable Codex/Claude worker with the appropriate libraries or export tools. These are worker-dependent outputs. PowerPoint .pptx generation has its own implemented Relay operation, listed above; it does not include existing-template editing or PDF export.

Additional image providers

OpenAI and OpenRouter image stages save PNG candidates. Runway and Higgsfield provide image and video generation; Meshy creates untextured GLB assets from text. Choose defaults under Models by task and connect the relevant API accounts. These new provider adapters have controlled tests; live generation remains unqualified.

Formats without a built-in route

Native Keynote .key and Grasshopper .gh/.ghx are not supported. CAD/mesh exchange formats such as .dwg, .dxf, .obj, .stl and .fbx are not standard Relay export operations; any such export needs a separately scoped tool or script. Meshy’s .glb generation does not provide general GLB import or export.

A program’s ability to open a format does not mean Relay can automate it. Support depends on the operation, installed tools and selected files.

07 / Get started

Start a job from Telegram.

Task Relay runs locally on your Mac. Telegram is the current interface for sending instructions, receiving files, reviewing progress and answering questions.

Package contents: 0.13.0 beta.1 includes Browser use settings, separate model defaults, Runway/Higgsfield image and video adapters, Meshy text-to-3D, editable PowerPoint generation, and workflow starters. Install with CLI instead

For developers on macOS or Linux. Requires Python 3.11+, curl and tar. Download this beta’s source, then run the guided terminal setup:

curl -fLO https://task-relay-website-production.up.railway.app/downloads/Task-Relay-0.13.0-beta.1-source.tar.gz
tar -xzf Task-Relay-0.13.0-beta.1-source.tar.gz
cd task-relay-0.13.0-beta.1
sh install.sh --terminal-setup

The installer creates its own environment and prints the installed CLI path. Keep that folder in place. Optional CLI capabilities require their extras: images, presentations or browser. Setup saves connections without starting provider work. Follow the printed instructions to start Relay and pair Telegram.

The CLI honors the data connection already selected in the companion. Existing login services are preserved; switching their owner requires a reviewed handoff. Linux service support depends on an available user service manager.
