# Support-first CA · cells to timber reel

The bundled template uses Codex, isolated Python, Blender, Gemini, HyperFrames
and FFmpeg. It replays the supplied support-first CA study; it does not regenerate
its cellular automaton. The saved graph has 6549 cells and 13082 links. These are
experimental design data, not a structural or joinery qualification.

`workflow.json` is the portable 11-node graph. `manifest.json` names four starter
files and binds their exact bytes. The corresponding distribution is
`task_relay/assets/job-templates/support-first-ca.workflow.zip`. Its entries are
`manifest.json`, `workflow.json` and `inputs/<id>` for each manifest input. The
source files here are checked against the packaged bytes by template tests.

Choose Jobs → Templates → Use template to import new immutable copies and an
editable draft. Configure the tools, review the exact Blender script and paid
Gemini request, and run the nodes. Preview must finish before selecting Export
final reel: export binds the exact completed preview and project archive.

The soundtrack uses local Python and graph-derived event schedules. HyperFrames
assembles the two Blender sequences, new Gemini visualization, captions and
soundtrack into a 12-second 1080×1920 reel. No historical output, approval,
execution receipt, local path or creator website is imported.
