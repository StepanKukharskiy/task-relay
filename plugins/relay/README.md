# Task Relay for ChatGPT

**Turn useful ChatGPT conversations into reusable Skills and work you can pick up again.**

Task Relay 0.4.2 is a skills-only plugin. It uses ChatGPT's native conversation
and file capabilities. No Relay server, tunnel, custom panel, separate account
or Desktop connection is required.

After useful discussion, invoke Task Relay and say **Make this reusable**.
ChatGPT proposes reusable instructions as a standard Agent Skill and progress as
a work snapshot. Review, edit, save or ignore each independently. Nothing is
saved automatically. Explicitly approve the output(s) you want, then ChatGPT
creates portable files using its available file tools.

In a fresh chat, attach/select your saved Skill, work snapshot or both and say
what to do next. **Continue saved work** uses those files and your new request,
without reconstructing the original chat. **Update saved work** and **Improve
Skill** create independent proposals and new files; they do not overwrite prior
versions or install Skills automatically.

Skills use the standard folder containing SKILL.md and relevant supporting
resources. Work snapshots preserve objectives, conclusions, decision/proposal
status, evidence, artifact references, open questions and next actions. Artifact
references are not their contents; supply a referenced file when needed.

There is no complete-history access, automatic latest-file discovery, persistent
Relay catalog, cloud synchronization or local execution. File creation and
selection depend on native capabilities available in the current host. The
plugin must explain unavailable capabilities without fabricating saved files.
