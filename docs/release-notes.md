# Task Relay 0.12.0

- Guided source installation, resumable provider/Telegram/project setup and local
  diagnostics independent of Codex desktop.
- Explicit release installation, gated service switching, code rollback and
  interrupted-activation recovery for compatible Telegram-only core installs.
- Daily stable-release checks and one Telegram notice per newer version, with an
  option to disable both checks and notices.

This is an active-development release. Windows execution, explicit data migration,
separate Messages deployment updates and native Linux service-switch acceptance
remain open. Controlled macOS service checks do not establish provider access or
real Telegram delivery. See [update instructions](https://github.com/StepanKukharskiy/task-relay/blob/v0.12.0/docs/updates.md) and the
[roadmap](https://github.com/StepanKukharskiy/task-relay/blob/v0.12.0/ROADMAP.md) for supported scope and remaining work.
