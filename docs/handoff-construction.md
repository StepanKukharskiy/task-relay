# Shared handoff construction

Code owns reference placement and compiler-created evidence paths. An owner may
supply an exact data/baseline reference beside a work intent or inside it. Construction
normalizes a copy; the submitted intent remains in the original journal. Conflicting
references, wrong modes, unknown fields and scope violations reject without effects.
This supplies no new operation, provider, attempt, capacity or authoring authority.

Independent inspection reuses a collected completed output by its exact artifact
identity. Inherited artifact references and task-output references to that same
output are one inspection input. Pending tasks keep their unresolved output identity;
identical bytes from different artifacts are not treated as interchangeable.

When distinct generated inspection evidence needs an occupied path, code allocates
a deterministic unused evidence alias and records the selected identity/path. It
preserves every existing input binding and registered output path. It never rewrites
producer documents, drops evidence, repeats inspection or infers acceptance.

The same bounded admission and final-review requirements apply. Invalid semantic
choices remain decisions for the model; partial delivery remains distinct from full
approval. Controlled qualification and live results are recorded separately in
private qualification records
